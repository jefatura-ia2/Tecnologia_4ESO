# Checklist de Impresión 3D — [Nombre del Proyecto]

## Pre-impresión

- [ ] STL verificado sin errores en Bambu Studio
- [ ] Orientación óptima configurada
- [ ] Material correcto cargado en AMS
- [ ] Perfil de impresión seleccionado
- [ ] Soportes configurados (tree/pintados)
- [ ] Cama limpia (IPA para PLA/PETG)
- [ ] Calibración de primera capa realizada
- [ ] Tiempo estimado aceptable

## Durante impresión

- [ ] Primera capa adherida correctamente
- [ ] Sin warping visible
- [ ] Soportes generándose correctamente
- [ ] Sin stringing excesivo

## Post-impresión

- [ ] Retirar soportes con cuidado
- [ ] Verificar dimensiones críticas con calibre
- [ ] Verificar ajuste de PCB/componentes
- [ ] Instalar insertos roscados (si aplica)
- [ ] Lijar superficies de contacto (si necesario)
- [ ] Test de ensamblaje base + tapa
- [ ] Verificar acceso a conectores USB/cables
